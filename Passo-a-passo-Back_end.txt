Passos:

1 - No VSCode:
===============

Executar no Bash:
=======

npm install express
npm install mysql2
npm install cors
npm install nodemon --save-dev

Para que serve cada biblioteca?
===============================
Biblioteca	Função
express		Cria o servidor Web/API
mysql2		Conecta o Node.js ao MySQL
cors		Permite que o HTML acesse a API
nodemon		Reinicia o servidor automaticamente durante o desenvolvimento
